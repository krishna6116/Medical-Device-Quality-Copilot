# Phase 3 spot-check: 20 reference labels for you to review

Selected by a fixed rule (md5 order of the report key, 10 validation + 10 test), not by hand. For each report, read the text and say **agree** or **disagree** (and, if you disagree, which mode you would pick). The codebook rule: one primary mode = the problem that made someone file the report; if several are named, the most specific cause in the family's priority order wins, and a stated cause beats its symptom. Full definitions: `config/failure_modes.json`.
