# Phase 8: the Streamlit app

_Generated by `python -m dashboards.report_phase8`. Do not edit by hand._

**Live app:** not deployed yet.

The app shows the project to someone who will not install anything. It reads only the committed snapshot files in `dashboards/snapshots/`: it never calls the Claude API (recorded answers are replayed) and never connects to a database. Run it locally with `.venv-app\Scripts\streamlit run app/streamlit_app.py` after `pip install -r app/requirements.txt`.
