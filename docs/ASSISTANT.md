## How it works

A quality engineer asks a question in plain English. The model (`claude-haiku-5-5`, effort medium, up to 10 calls and 4,000 output tokens per call) decides which tools to call, reads their JSON results and answers with citations. It never writes SQL, and every number it states must appear in a tool result. Around every call the project's own loop keeps a cost ledger from the API's token counts, enforces a budget stop, and records the exchange so the demo and CI replay it for free (`python -m mdqc.replay Q1`).

| Tool | What it does |
|---|---|
| list_manufacturers | List the companies with the most reports for a product code (optionally one failure mode and date range), with counts and shares. Use it to find exact company names or compare companies. |
| count_reports | Count adverse-event reports matching filters, split by event type (Malfunction, Injury, Death, Other). |
| trend | Report counts over time (month, quarter or year) for the given filters, with the first-to-last change. |
| failure_modes | Break the matching reports down by failure mode, with counts, shares and definitions. |
| search_reports | Find reports whose narrative is similar in meaning to a description. Returns report keys and excerpts; identical template texts are collapsed. |
| get_report | Full details of one report: dates, company, device, FDA problem terms, failure mode, narrative and recalls linked within a year. |
| find_recalls | List recall records (most recent first) by product code, company, start date range or words in the recall reason. |
| signal_check | Early-warning signals (months with unusually many reports) for a product code, optionally one company and failure mode. |

## Limits

- The scripted stand-in shows the plumbing works; it says nothing about how well a model chooses tools or reads results. That is Phase 6.
- Grounding checks that numbers and citations come from the tools, not that the answer is right; Phase 6 adds gold answers.
- Failure modes come from FDA problem terms (about 70% agreement with reference labels, Phase 3), so a report's mode can disagree with its narrative.
